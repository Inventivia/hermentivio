# HermentivIO

HermentivIO es el asistente IA de Inventivia Marketing.

Objetivo inicial: documentar, organizar y evolucionar el sistema de agentes, automatizaciones y herramientas IA que ayudan a Inventivia a trabajar mejor, vender servicios de mayor valor y reducir trabajo manual.

## Estado

Repositorio inicial creado para preparar la base del proyecto.

## Estructura

```text
src/        Código fuente del proyecto
docs/       Documentación funcional y técnica
config/     Plantillas de configuración sin secretos
scripts/    Scripts auxiliares
```

## Seguridad

No subir claves, tokens, contraseñas ni archivos `.env` reales.
Usar `.env.example` como plantilla.
